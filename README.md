# JK Foundry Website

This is the official website for JK Foundry, a manufacturer and supplier of precision steel cast components for trucks, trolleys, industrial equipment, and general engineering.

## Features

- Modern, responsive design
- Detailed product showcase
- Company information and infrastructure details
- Contact form with sample request functionality
- WhatsApp integration for direct communication

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm or bun

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/jk-foundry-website.git
cd jk-foundry-website
```

2. Install dependencies:
```bash
npm install
# or
bun install
```

3. Run the development server:
```bash
npm run dev
# or
bun dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the website.

## Project Structure

- `src/app/` - Next.js app router pages
- `src/components/` - Reusable React components
- `public/` - Static assets like images and fonts
- `tailwind.config.js` - Tailwind CSS configuration

## Deployment

This website can be deployed to any platform that supports Next.js, such as Vercel, Netlify, or a traditional server.

### Build for Production

```bash
npm run build
# or
bun run build
```

## Customization

### Adding Real Images

Replace the placeholder images in the `public/` directory with actual images of JK Foundry's products, facilities, and team.

### Updating Content

Update the content in the page files to reflect the latest information about JK Foundry's products, services, and contact details.

## 4. BRANDING & STYLE GUIDE

### 4.1. Logo Usage
- Use the provided "JK Foundry" logo in the top-left corner of the website header (desktop) and a condensed version in mobile view if needed.  
- Maintain ample white space around the logo.  
- For the site favicon, consider a simplified "JK" or the pouring crucible graphic.

### 4.2. Color Palette
Given the logo's molten metal theme, the suggested color scheme is:

1. **Primary Accent (Molten Orange):** #F2A600 (approx.)  
   - Used for buttons, highlights, icons, call-to-action elements.  
2. **Dark Gray (Text/Headers):** #333333 or #444444  
3. **Light Gray (Background):** #F9F9F9 or #EEEEEE for sections.  
4. **White:** #FFFFFF for main backgrounds, hero text, etc.  
5. **Secondary Accent (Steel Gray):** #6F6F6F or #7C7C7C  
   - For secondary text or subheadings.

Ensure color contrast is sufficient for readability (especially for text on orange backgrounds).

### 4.3. Typography
- **Heading Font:** Montserrat (or similar clean, bold sans-serif)  
  - Weight: 600 or 700 for headings.  
- **Body Font:** Open Sans or Roboto (sans-serif)  
  - Weight: 400 for regular text, 500 for subheadings.  
- **Font Sizes (Desktop)**  
  - H1: ~32px  
  - H2: ~28px  
  - H3: ~24px  
  - Body: ~16px  
  - Small text / captions: 14px  
- **Line Height:** 1.5 for readability.
